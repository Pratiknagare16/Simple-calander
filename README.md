📅 Simple Calendar

A simple web-based calendar application built using HTML, CSS, and JavaScript. This project displays a basic interactive calendar that helps users view dates easily in a clean UI.

🚀 Features

📆 Displays a monthly calendar

🔄 Navigate between months

🎨 Simple and clean UI design

⚡ Built with vanilla JavaScript (no frameworks)

🛠️ Technologies Used

HTML – Structure of the calendar

CSS – Styling and layout

JavaScript – Calendar logic and interactivity
